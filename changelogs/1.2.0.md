# Rocher Suchard 1.2.0 — Horizons mécaniques

Cette release élargit fortement le pack autour de trois axes : **Create et l'aéronautique**, **l'exploration**, et **la construction/décoration**. Elle ajoute également un vrai canal de développement isolé pour tester les prochaines évolutions sans déplacer la release stable.

> [!WARNING]
> **Migration Distant Horizons — vérification manuelle recommandée**
>
> Distant Horizons est volontairement verrouillé en **3.3.1** pour rester compatible avec **SSRD 1.8.6**, et son auto-updater est désactivé.
>
> Lors d'une mise à jour d'une instance existante, Packwiz peut télécharger le bon jar sans supprimer un ancien jar Distant Horizons installé auparavant par l'auto-updater. Nous avons reproduit le cas avec **3.3.3** : les deux versions restent alors dans `mods/` et Minecraft refuse de démarrer.
>
> **Avant le premier lancement après mise à jour**, vérifiez le dossier `mods/` et supprimez toute ancienne version de Distant Horizons. Il ne doit rester que :
>
> `DistantHorizons-3.3.1-1.21.1-fabric-neoforge.jar`
>
> Si Minecraft signale plusieurs versions de Distant Horizons, fermez le jeu, supprimez l'ancien jar et relancez.

## 🧪 Nouveau canal DEV

Le dépôt dispose maintenant d'une chaîne de publication dédiée aux tests :

- builds de développement isolés depuis `dev` ;
- branche générée **`dev-latest`** ;
- releases GitHub DEV séparées des releases stables ;
- bundle **Prism DEV auto-actualisé** utilisant Packwiz ;
- export `.mrpack` figé disponible pour reproduire précisément un build ;
- garde-fous empêchant un build DEV de déplacer les endpoints de release stable ;
- documentation dédiée dans `deploy/DEV.md`.

Cela permet de tester les grosses évolutions du pack avant leur promotion vers `main`.

## 🔄 Migration

Pour une nouvelle installation, utilisez simplement les artefacts de cette release.

Pour une instance existante :

1. faites une sauvegarde de l'instance et du monde ;
2. mettez à jour le pack ;
3. **vérifiez manuellement qu'une seule version de Distant Horizons est présente dans `mods/`** ;
4. supprimez toute ancienne version DH si nécessaire et conservez uniquement la 3.3.1 ;
5. mettez à jour client et serveur ensemble ;
6. explorez de nouveaux chunks pour profiter des nouveaux biomes et contenus de génération.
